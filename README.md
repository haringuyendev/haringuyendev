### About Me

Senior Fullstack & AI Systems Engineer based in **Ho Chi Minh City, Vietnam**.  
I design scalable enterprise backends with **Clean Architecture** and **Microservices**, build **AI-native developer tooling** (multi-agent SDLC harnesses & MCP context engines), and ship fullstack web & mobile applications.

- **Architecture Focus**: `Clean Architecture` · `Microservices` · `Event-Driven Systems`
